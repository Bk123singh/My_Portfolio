## ⚡ Quickstart

### Prerequisites
- Node.js >= 18.x
- npm

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

The production output will be generated inside the `dist/` directory, ready to be deployed to Vercel, Netlify, or GitHub Pages.
